# Contributing

PRs welcome. Three house rules, in order:

1. **Never-submit is sacred.** No code path may submit an application, send
   an email, or send a message on a user's behalf. Pre-fill and stop.
2. **No invented facts.** Tailoring/answers features must keep the
   no-invention guard (`check_no_invention`) green.
3. **Respect source terms.** New source adapters must use official APIs or
   public pages, document their terms status at the top of the file, rate
   limit politely, and stop on blocks — no CAPTCHA bypass, no login scraping.

Run tests with `pytest`.
